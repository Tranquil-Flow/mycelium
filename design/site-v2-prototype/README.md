# Site V2 prototype (mock data, no backend)

Design prototype for `docs/design/SITE-REDESIGN-V2.md`. Every number is invented except the "Mycelium demo" listing's name, model, access
mode and quota. Nothing here talks to a network.

```sh
cd design/site-v2-prototype
python3 -m http.server 8765 --bind 127.0.0.1        # then open http://127.0.0.1:8765/index.html
python3 build.py                                    # regenerates the six .html pages from one shared shell
python3 tools/capture.py                            # screenshots + layout-shift gate (needs playwright)
python3 tools/behaviour.py                          # 20 click-through assertions
```

| Page | Shows |
|---|---|
| `index.html` | apex explainer + light "Right now" status |
| `swarms.html#browse \| #chat \| #contributing \| #owned` | the app tabs |
| `swarm.html?id=reading \| demo \| lab \| weekend \| studio \| garage \| family` | detail with stats (serving, warming, offline) |
| `chat.html?id=<id>&state=first\|ready\|needs-request\|pending\|approved\|declined\|expired\|quota\|invite\|busy\|offline\|killed` | chat in every access state (switcher in the top bar) |
| `owner.html` | request inbox, default policy, people, setup, access policy, emergency stop |
| `create.html` | create a swarm with the registered-model dropdown |

`.html` files are generated by `build.py`; edit that, `site.css`, `app.js` or `mock-data.js`, not the generated pages.
