Create or join a swarm

Assigned cooperative workers can observe the prompts, outputs or intermediate activations needed for their work, including sizes and timing. This is not confidential inference from the assigned worker.

02 · Evidence, not assumptions

Device readiness

Runs a tiny local arithmetic check, not a model. Signed self-report is not independent qualification.

Membership is not assignment. Assignment is not load. Only fresh native qualification and selection permit inference. Distributed serving requires two separate physical Macs.

Pair another authorized Mac

On the second Mac, choose “Join an existing swarm” above. Send its public request to the owner. The owner reviews the identity and limits, then returns only the encrypted invitation. Network reachability still requires separately approved HTTPS setup; you can start the public relay in the invite section before or after creating the swarm.





02b · Coworking join
Invite or join with a code


Each code admits one Mac, expires, and travels only through your public HTTPS relay. You see the Mac’s fingerprint, chip, memory and measured relay link, then approve it with one click. No files, no SSH.


Codes can be asked for at any time. With the temporary public relay (a Cloudflare quick tunnel) the address only exists once the relay starts, so a code made before that shows “ready to share once the relay starts” and becomes redeemable the moment the relay is up. Serving needs the relay.



Use my own address
Advanced. Instead of a random temporary Cloudflare address, serve this swarm on a fixed https address you own (for example https://demo.mycelium.now), so join links and the swarm listing keep working after the relay restarts. Mycelium does not create this address: you must point this hostname at this Mac yourself, for example with a Cloudflare named tunnel whose service is http://127.0.0.1:<port> using the port below. The front you use terminates HTTPS and can see control traffic and web chat in plaintext.

    03 · Native model-stage work
    Inference
    Not yet serving
    Acquire the selected model
    Downloads the pinned model snapshot from Hugging Face onto this Mac and checks every file against its pinned digest. The exact size and the storage it needs for the selected model appear here once the status loads. Files already on this Mac (a retained or LAN-seeded copy) are verified and not fetched again; the byte limit below caps what may be downloaded from the network in one attempt. Fetching verifies source files only: it does not convert, load, qualify or run a model.
    Uses this installation's storage limit. AC/battery, thermal and network policy are checked before transfer and monitored during acquisition. Unknown observations stop acquisition. Interrupted bytes remain private for an explicitly requested retry.
    Execution, receipt integrity and output correctness are separate. Publishing a swarm listing requires the separate owner action above.
    

    Prepare this target Mac
    A signed offer supplies bounded staging files from your swarm owner. Review its digest before acceptance. Staging does not authorize model execution or qualify this device.
    Bounded native control
    Permit native identity and control commands for this run: at most 5 minutes, 512 MiB process memory and 1,000 commands. Saved power, thermal, network and storage policies remain enforced. This does not authorize loading or running the model.
    

    Remove staged run files
    Only the exact run requested by your swarm owner is removed, after you stop native control and approve here. Device identity and recovery evidence remain.
    

    03d · Pause and adapt
    Adaptive sharing
    Mycelium watches this Mac's memory, CPU, heat and battery. When other apps need resources, it automatically shares less and pauses sharing. Work in progress may stop; fast mode cannot recover an answer if a Mac drops. It resumes once the Mac has been healthy for a while. Your own apps always come first.
    Adaptive sharing off means nothing is reduced or paused automatically. Your memory limit and disk-space floor, your power, heat and network limits, Pause sharing and Stop are enforced either way. It reads only coarse memory pressure and, if you set it, overall CPU load, never which apps you run.
    Impact: a short background check every couple of seconds; this Mac may stop serving while you use other apps; it returns only after about two minutes of calm and a fresh check with the swarm.
    




    

    

    04 · Stay in control
    Pause, restart, or leave
    Stop retains your identity, membership recovery and evidence. Restart never silently creates a replacement identity. Revoke withdraws membership authority; it is different from deleting local files.
    To close Mycelium, use “Quit demo” below. The macOS menu Quit is not supported by this launcher yet; closing the browser tab does not stop the app.
    To remove the application, quit first and move the app to Trash. Keep private state for recovery. Explicit private-state removal is documented in the runbook; no secure-erasure claim is made.
    

    04b · Leave
    Leave swarm
    Only for a Mac that joined a swarm. Either way this Mac stops accepting work, withdraws its standing consent and stops renewing its membership; your identity and files stay on this Mac.
    Leave smoothly: stops new work and lets what is already running finish (up to 30 seconds, then it leaves instantly), so the swarm can plan around you.
    Instant leave: disconnects now, like losing the internet; the swarm adapts on its next request.
