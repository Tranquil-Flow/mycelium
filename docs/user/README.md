# Mycelium user guides

Plain-language guides for people who just want to use Mycelium. All of them describe the macOS (Apple silicon) preview. Windows and Linux are not available yet.

- [QUICKSTART-MACOS.md](QUICKSTART-MACOS.md): install the signed app and start a swarm with two Macs.
- [TROUBLESHOOTING.md](TROUBLESHOOTING.md): what a message means and what to do.
- [WHAT-MYCELIUM-DOES.md](WHAT-MYCELIUM-DOES.md): the features, and how far each has been proven.
- [PRIVACY.md](PRIVACY.md): what stays on your Macs and what other parties can see.
- [OPENAI-API.md](OPENAI-API.md): use your private swarm from curl or the Python `openai` package, with keys and quotas you issue.

Every page ends with a Sources list of the code and reports its claims come from. Anything not yet verified on real hardware is labelled as such.
