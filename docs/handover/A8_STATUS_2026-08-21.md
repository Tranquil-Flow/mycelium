## Gotchas that cost time

- `seal_qualification` requires a pre-existing 0700 evidence root; it does not
  create one. A missing dir fails with `evidence_root_unsafe` *after* the invite
  and node identity are consumed. Create the dir first.
- Invites are single-use — mint one per case, with distinct nonces.
- Give every case its own node root; reuse collides on durable identity.
- The rehearsal seed keeps members in memory (no `state=`), so revocation cannot
  be done by a separate process against the same sqlite file.
