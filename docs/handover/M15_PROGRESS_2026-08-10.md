# M15 completion — phase and workload intelligence

## Outcome

M15 is complete for the explicitly sequential three-device physical boundary. The
planner evaluates `balanced`, `prefill_ttft`, and `decode_tpot` policies over the same
frozen M13 signed snapshot and M14 measured directed topology. It emits deterministic
scenario matrices, exact contiguous allocations, phase-separated predictions, minimax
normalized-regret winners, Pareto membership, and signed candidate deltas.

The product does not claim request admission, concurrent execution, continuous
batching, queueing, or batch-shape execution. Those fields remain
`deferred_to_m16` in code, contracts, physical evidence, and UI.

The pure planner gate contains a heterogeneous capability matrix where the prefill
objective yields a 7/1 split and the decode objective yields a 1/7 split over the same
topology and evidence. On the measured physical matrix all policies truthfully select
the same 1/1/22 split.

## Next boundary

M16 adds resource reservations, admission, progressive prefill, immutable request
paths, bounded QoS queues, batching, and backpressure. It must not inherit the broad
M15 model-error bound as a permanent quality target; additional calibration samples
should tighten the prediction model before performance-based routing is trusted.
