## Implemented

- Closed canonical stage-pack manifests bind the immutable model revision,
  representation decision, feasibility generation, assignment, execution graph,
  member generation, placement, layer interval, exact file/component/tensor scope,
  byte stream, fixed chunks, Merkle proofs, and expiry.
- Closed signed availability and grant contracts reject stale generation, manifest,
  recipient, representation, feasibility, unknown-field, and signature drift.
- Peer range transport now requires certificate-validated HTTPS, a fresh recipient-
  signed request containing the exact Provisioner grant, and a source-signed receipt
  binding the returned bytes. Successful request IDs are fenced by a durable,
  cross-process replay store.
- A platform-neutral member artifact agent loads the member's existing durable node
  identity, verifies content-addressed objects, emits generation-bound signed
  availability bundles, and serves only authorized manifest ranges. Its private
  digest-named manifest inbox is reconciled atomically without restart; invalid inbox
  state leaves the last valid authority active, and unchanged availability is renewed
  before expiry. It contains no Pixel-, Lenovo-, macOS-, or Linux-specific serving
  behavior.
- Artifact sources are now an explicit generic role in the existing versioned
  launchd/systemd service-package contract. The shared runner persists a bounded
  restart budget and privacy-reduced status while the platform manager provides boot
  and login durability. This packages the same platform-neutral agent rather than
  introducing host-specific source logic.
- A platform-neutral recipient executor now runs the Provisioner on the assigned member
  under that member's durable identity. It validates a closed private job, current
  signed source bundles, the signed Provisioner grant, source generations and keys,
  certificate-validated HTTPS receipts, exact assignment binding, and local atomic
  promotion. It has no implicit coordinator-origin path. The end-to-end transport test
  proves recipient-side promotion and rejects membership-generation drift.
- The Provisioner supports content-addressed verified chunks, bounded parallel source
  scheduling, serving reserve policy, retries, source rotation, verified-prefix resume,
  origin fallback, duplicate suppression, disk reservation, one-writer locking,
  quarantine, cancellation, restart recovery, and deterministic terminal accounting.
  The byte-rate budgets are enforced by shared aggregate and per-source leaky-bucket
  schedules and remain cancellation-responsive while waiting for bandwidth.
- Signed peer grants are durably consumed by exact grant ID and nonce before disk
  reservation or transfer. Replay survives recipient process restart, while a fresh
  grant may reuse already verified chunks. Failed final attempts retain observed
  quarantine, verified-prefix duplication, and source-rotation accounting.
- Promotion streams verified chunks directly into the private assignment file tree,
  verifies every file and the concatenated pack digest, fsyncs the tree, and atomically
  renames it. It does not retain redundant full-pack copies.
- Candidate preparation builds acquisition manifests and passes every model artifact
  through the Provisioner. A recipient-owned promoted pack is bound into a closed
  controller preposition document; that member's coordinator archive omits those model
  bytes. The remote stage program verifies the current-user-owned promoted source,
  symlink-free path, exact size and digest, copies it into a new private staging root,
  verifies the destination, and binds both archive and preposition digests in its
  acknowledgement and cleanup marker. A remote preparation now fails explicitly with
  `member_artifact_transport_unconfigured` unless a member executor is installed; it no
  longer falls back to copying coordinator-promoted bytes while calling that peer
  acquisition. The local-member path may still use the explicitly authorized operator
  origin and is reported as such.
- Preparation now checks capability-evidence freshness once at the trusted start of an
  attempt, then issues all of that attempt's manifests under one bounded 15-minute
  artifact-only lease. The lease cannot activate or place a candidate, and later
  qualification remains mandatory. This prevents a valid sequential multi-stage
  transfer from inheriting an already-expired short observation lease while preserving
