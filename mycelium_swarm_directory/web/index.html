Demo. Hosted on one volunteer Mac: it may sleep. No accounts, no tracking.

How it works

  1. Create a swarm with a name and a model. You own it with this browser's key.
  2. Add a helper Mac. The Mac that runs the Mycelium app serves the swarm; more Macs join it with an invite.
  3. Choose who may use it: open to anyone (with a quota), by request (you approve), or invite only.
  4. Run inference here in the browser. Tokens appear as the route makes them, and the end of every prompt is named.

AGPL-3.0 · Mycelium · This directory sets no cookies, runs no analytics and keeps no logs. Cloudflare terminates TLS for this site and for every swarm entry on trycloudflare.com, so Cloudflare can see your IP address, request timing and, when you chat, your prompt and the reply in plaintext. A prompt goes from your browser directly to the swarm's entry Mac, never through this directory; that Mac sees your prompt and IP address too, and a swarm is run by whoever runs its entry Mac, not by Mycelium.
