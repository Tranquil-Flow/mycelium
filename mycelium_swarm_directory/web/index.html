✳ Mycelium public swarms

Demo. Hosted on one volunteer Mac: it may sleep. No accounts, no tracking.

How it works

  1. Create a swarm with a name and a model. You own it with this browser's key.
  2. Add a helper Mac. The Mac that runs the Mycelium app serves the swarm; more Macs join it with an invite.
  3. Choose who may use it: open to anyone (with a quota), by request (you approve), or invite only.
  4. Run inference here in the browser. Tokens appear as the route makes them, and the end of every prompt is named.

Your browser key

This browser made an Ed25519 key that never leaves it (non-extractable, stored in this browser only). No email, no password, no account. Owners grant access to this key's fingerprint.

Creating your key…

Forget this browser key?

This deletes the key from this browser, with every grant and open-access allowance saved with it. You can no longer manage the swarms you own with it (their owner key is gone for good), and the access owners gave this key stops working here.

The next visit makes a new key: a new identity with a fresh per-key quota. That does not reset the limits counted by network address, which the swarm's entry applies to everyone, nor a swarm's daily cap for open access.

All swarms

Your prompt is seen by the swarm's nodes (the Macs that run it).

What happens to your prompt

  • Who runs a swarm. Each card shows the owner's key fingerprint: the key that signed its listing. A swarm is run by whoever runs its Mac, not by Mycelium.
  • Where it travels. Your prompt goes from this browser straight to the swarm's own relay (never through this directory), an HTTPS service that can read it in plain text, then to the owner's Mac and on to the volunteer Macs that compute the answer. Those Macs can see your prompt and the activations. Do not type secrets.
  • What is stored. This directory stores no prompts and sets no cookies; your key and grants stay in this browser. Prompts and answers are not stored by the directory or the chat page. The owner's Mac keeps the last 64 answers in memory so your browser can fetch them. The people who run the relay and the Macs could keep their own logs.
  • Your quota. An open swarm's card shows its quota (requests and tokens per key). Limits per network address and a daily cap for the whole swarm also apply.
